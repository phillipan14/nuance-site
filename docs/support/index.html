Support

Common questions about using Nuance.

Getting started

How do I add Nuance as a keyboard?

iPhone Settings → General → Keyboard → Keyboards → Add New Keyboard → tap Nuance.

Then tap on Nuance in the list and toggle Allow Full Access if you want Smart Mode (network-using AI translation). Quick Mode works without Full Access.

How do I switch to the Nuance keyboard?

In any text field, tap the globe key (🌐) at the bottom-left of your keyboard. It cycles through your enabled keyboards. You can also long-press the globe key to pick Nuance directly from the list.

What's the difference between Quick and Smart mode?

Quick Mode uses Apple's on-device Translation framework. Fast, works offline, runs entirely on your device. Best for short messages, signs, menus.

Smart Mode uses an AI service (DeepSeek) for tone-aware translation. Pick a tone — Friendly, Professional, Direct — and Nuance rewrites the way a native speaker would. Requires Full Access + internet.

Privacy

Does Nuance log my keystrokes?

No. Nuance only sees what's in the compose area (the text you've typed for translation). Once you tap Translate, that text is processed (on-device for Quick Mode, sent to DeepSeek for Smart Mode). Nothing is logged or sent elsewhere.

What data goes to DeepSeek in Smart Mode?

Only the text you've explicitly typed for translation, plus the target language and tone you selected. No contacts, no other text, no photos, no location, no device identifiers.

See the full privacy policy.

Can I use Nuance entirely offline?

Yes — Quick Mode works fully offline. Long-press the tone chip to switch to Quick Mode (vermillion thumb). Only Smart Mode requires internet.

Troubleshooting

The keyboard isn't appearing in Settings → Keyboards

Make sure you've launched the Nuance app at least once (iOS only registers keyboard extensions after the host app has run). Then go to Settings → General → Keyboard → Keyboards → Add New Keyboard and look for Nuance.

Smart Mode isn't translating

Check that you've enabled Allow Full Access for the Nuance keyboard (Settings → General → Keyboard → Keyboards → Nuance → Allow Full Access). Without Full Access, the keyboard cannot make network requests, which Smart Mode requires.

Can I use my own DeepSeek API key?

The default Smart Mode uses a built-in API key. If you have your own DeepSeek API key, you can paste it in the Nuance app's settings to use your own quota instead.
